# NexusPSA P&ID symbol sources

The hydraulic palette uses vector symbols with fixed aspect ratios.

- **Motor Pump**: NexusPSA master symbol validated by the project owner.
- **Standard hydraulic components** (check valve, manual/motor operated valves, diaphragm, safety/relief valve, tank): geometry is based on conventional P&ID/ISO-style symbols and cross-checked against the diagrams.net/draw.io P&ID stencil library.
- **Project-specific support symbols** (KD, FIP, I&C, electrical supply, maintenance, tester, source, transfer): original NexusPSA vector artwork, informed by the engineering legend supplied for this project.
- The PTR/RRI/SEC drawings are used only as engineering/visual references for component family selection, orientation and proportions; proprietary drawings are not embedded in this public repository.
